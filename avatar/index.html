Avatar Rotator

Automatically rotate your Roblox avatar between saved outfits, so it looks different every time someone reloads your profile — runs entirely in your own browser.

How it works

This tool never asks for your password or session cookie, and nothing you do here is sent to this site's server. Instead, you install a bookmarklet — a saved browser button. When you click it while on roblox.com (already logged in, as normal), it runs directly on that page and uses your existing Roblox session to talk to Roblox's own API. Your session never leaves your browser, and it stops the moment you close that tab.

1. Install

Drag this button to your bookmarks bar:

🎭 Avatar Rotator

If your bookmarks bar is hidden, press Ctrl+Shift+B to show it.

2. Use it

  1. Go to roblox.com and make sure you're logged in.
  2. Click the Avatar Rotator bookmark you just installed.
  3. A small panel appears on the page. Click Fetch My Outfits.
  4. Select the outfits you want to rotate through and set an interval.
  5. Click Start. Close the tab any time to stop.

Security

⚠ This runs with the same access as your normal roblox.com session. Only install the bookmarklet from a source you trust, the same way you'd be careful about any browser extension or userscript. The full source of inject.js is public — you're welcome to read exactly what it does before using it.
