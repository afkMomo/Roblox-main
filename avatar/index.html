Avatar rotator

Cycle your Roblox avatar through your saved outfits on a timer, right inside your logged-in Roblox tab.

Avatar Rotator
  1. Show your bookmarks bar with Ctrl + Shift + B
  2. Drag the blue button onto the bar
  3. Open www.roblox.com while logged in
  4. Click the bookmark, pick outfits, set a timer, then press Start
Can't drag it? Copied. Create a new bookmark and paste this as its URL.

Features

Auto-switch timer

Seconds, minutes, or hours, with one-tap presets. A live countdown ring shows when the next switch happens.

Visual outfit picker

All your saved outfits with thumbnails, search, and select all. Numbered badges show the rotation order.

Sequential, shuffle, random

Go in order, shuffle each cycle, or pick randomly. It never wears the same outfit twice in a row.

Start, stop, skip, wear now

Control everything live. Click any outfit or queue item to wear it instantly.

Minimize to a floating pill

Shrink it into a draggable mini player with the countdown. It remembers where you put it.

Remembers everything

Outfits, timer, and options are saved. Auto-resume continues rotating when you reopen it.

Detailed logs

Every request is logged with filters, copy, and save-to-file for troubleshooting.

Notifications and tab countdown

Optional desktop notifications, a countdown in the tab title, and a warning before you close a running tab.

Rate-limit safe

Backs off when Roblox rate limits and stops after repeated failures. Outfit data is cached to send fewer requests.

Good to know

  • Keep a Roblox tab open. The rotator runs inside that tab. If you close it or leave roblox.com, it stops. Click the bookmark again to resume.
  • Browsers throttle background tabs, so switches can run a little late when the tab isn't visible. A separate browser window works best.
  • This changes your account avatar. Other players see the new outfit when you respawn or rejoin a game.
  • Click the bookmark again to hide or show the panel. The rotation keeps running while it's hidden.

Safety

It only talks to *.roblox.com using your existing login, and the full source code is in this page. Never install a Roblox bookmarklet from someone else without reading it first. It runs with full access to your account.
